## Install
```
git clone https://github.com/tumayouzyo/RefGallery.git
```
if use Exif, `python -m pip install Pillow` within the same Python environment used to generate the gallery.

## Usage
local image
```
RefGalleryを使用して、"D:\xxx\xxx"をタグ振り分け
```
```
Use RefGallery to categorize "D:\xxx\xxx" using tags.
```
or web
```
RefGalleryを使用して、xxxについての資料を収集
```
```
Collect references on xxx using RefGallery.
```
